# Pinewood Derby Axle Alignment Guide / Jig

## Description

The Pinewood Derby Axle Alignment Tool is a precision jig designed to ensure that car axles are perfectly straight and parallel. This is critical for reducing friction and ensuring the car tracks straight down the lane. The tool features slots and guides for standard axle diameters and helps in both the insertion and adjustment of axles.
