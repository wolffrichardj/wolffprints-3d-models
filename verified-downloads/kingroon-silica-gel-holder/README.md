# Kingroon silica gel holder

## Description

Kingroon spool dry cap / lids silicagel dry box. Print two lids (cap) and you have a cheap dry box for Kingroon spool. This is a remix of 3Dcrabi's design. It allows you to keep your filament dry while stored on the spool. Compatible with Bambu Lab AMS units.
