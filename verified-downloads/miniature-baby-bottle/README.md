# Miniature Baby Bottle

## Description

This miniature baby bottle is a detailed, small-scale model designed for dollhouses, dioramas, or as a decorative item. The model features a multi-part design that allows for printing the bottle, cap, and nipple in different colors for a realistic look. It is scaled precisely for common miniature standards (e.g., 1:12) but can be easily resized as needed.
