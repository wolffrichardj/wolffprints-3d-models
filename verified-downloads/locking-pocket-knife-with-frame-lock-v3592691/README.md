# Locking Pocket Knife with Frame Lock

## Description

The Pocket Folding Knife Fidget with Frame Lock is a safe, 3D-printed interpretation of a classic folding knife mechanism. It utilizes a functional frame lock to keep the 'blade' in the open position and provides a satisfying tactile experience for fidgeting. Optimized for fast printing with minimal material (approx. 20g), it requires no supports and is designed for smooth, reliable action.
