# Pinewood Derby Inspection Box

## Description

Hello! I designed this inspection box for my son's Cub Scout Pack to check if the Pinewood Derby Cars are within tolerance.

&nbsp;

The inner dimensions of the box are sized to the maximum allowable length and width of the Pinewood Derby Car. The height of the box will also ensure the car is shorter than 3", to allow clearance of an electronic gate (if equipped on your track). Additionally, I added the minimum track clearances at the bottom of the box to ensure the kids' cars will go down the track without interference.

&nbsp;

Feel free to use the blank side of this box to add your Pack/Troop ...
